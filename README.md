Title: Banking Management System

Banking Management System is a simple console-based application developed in C++. It allows users to manage customer information, bank accounts, and basic banking operations through a menu-driven interface.

Features:
- Add and manage customer information
- Create and manage bank accounts
- Deposit money
- Withdraw money
- Check account balance
- Display customer and account details
- Store data using file handling
- Simple menu-driven console interface

Technologies Used:
- C++
- VS Code
- GitHub

C++ Concepts Used:
- Classes and Objects
- Encapsulation
- Constructors
- Access Specifiers (private, public)
- Functions / Member Functions
- Inheritance
- Polymorphism
- File Handling (fstream)
- Vectors (vector)
- Strings (string)
- Loops and Conditional Statements
- Menu-Driven Programming
- Pass by Value

How to Run:
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Make sure a C++ compiler is installed.
4. Open the terminal in the project folder.
5. Compile the program using: g++ Bank_Management.cpp -o Bank_Managgement
6. Run the program: .\Bank_Managgement.exe
7. Follow the instructions displayed in the terminal.
